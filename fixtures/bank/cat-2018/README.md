# CAT 2018 question archive

This directory contains both CAT 2018 examination slots: 100 questions per slot and 200 in total.

| Slot | VARC | DILR | QA | Total |
|---|---:|---:|---:|---:|
| 1 | 34 | 32 | 34 | 100 |
| 2 | 34 | 32 | 34 | 100 |

Each section has a searchable UTF-8 text file in this directory and a layout-preserving source PDF under `source-pdfs/`. The PDFs include answer or solution material. Use them for charts, diagrams, mathematical layout, and any detail that did not survive text extraction. Use the text files for search and review.

`answer-key.csv` records the answer and format of every numbered question in the order used by these files. MCQ answers are option letters matching the corresponding PDF; TITA answers contain the entered value.

## Sources and verification

Five source PDFs came from [BYJU'S CAT 2018 paper archive](https://byjus.com/free-cat-prep/cat-2018-question-paper/). Its Slot 1 DILR PDF reconstructs one matrix set incorrectly, so that section was replaced with the matching paper from [2IIM's CAT PDF archive](https://online.2iim.com/CAT-question-paper-pdf/). Question counts, formats, and answers were checked against [2IIM's 2018 section pages](https://online.2iim.com/CAT-question-paper/) and the [Arun Sharma Academy Slot 1 DILR archive](https://www.arunsharmaacademy.com/resources/cat-previous-year-papers/2018/slot-1/dilr).

Two BYJU'S source PDFs contain omitted or inconsistent answer labels. The searchable text and CSV correct them:

- Slot 1 QA Q4: option `D` (`5`)
- Slot 2 QA Q15: option `A` (`s ≥ 6`); the PDF derives this inequality but mistakenly concludes option C

The source PDFs are retained without modification so their provenance and original layout remain intact.
