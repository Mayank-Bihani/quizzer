Quizzer Design System · Artifact 3 of 5

Live quiz run

The highest-stakes surface, designed at 375px and one-thumbed throughout. Two rules govern every component here and are enforced in the markup, not just the prose.

■
No correctness, anywhere. The option and answer components have idle / pressed / selected / submitting / locked and no correct/incorrect state at all. There is no green tick, no red cross, no score delta, no "your answer was…" — those exist only in Batch 4's review components, after the hard deadline.
◇
Two clocks, two vocabularies. The per-question clock is a ring or bar with a grace zone, drawn in --accent-500 / --q-timer-grace / --q-timer-urgent. The window deadline is always digits on a dark pill in --q-deadline-fill, never a ring, never accent-coloured, never animated. Shape and colour differ, so they cannot be confused at a glance.

Pick sheet — Batch 3

ComponentABCRecommended

Open questions

  • Grace window semantics. Rendered as: answering within the first 10s earns the full bonus, after which it decays linearly to 0 at 45s. If instead the grace is a trailing allowance (extra seconds after the limit), variant B's zone must move to the right-hand end and the copy inverts.
  • Does the per-question clock keep running during a disconnect? Assumed yes (server-authoritative). The resumed-after-disconnect copy depends entirely on this.
  • Unsubmitted answer at the hard deadline. Assumed not counted. If it is counted, variant A's copy and the finish-card count both change.
  • Skipping. The brief never mentions skipping. Rendered as: no skip control — a question ends only by submitting or by expiry (which counts as unanswered, not wrong). Confirm; a skip button would change the submit bar in every variant.
  • Time-expired = unanswered or wrong? Assumed unanswered (0), not wrong (−1). This is the single most consequential assumption in this batch.
  • Passage sets and the per-question clock. Assumed each question in a set has its own 45s and the passage reading time is not separately allotted. If a set has one combined clock, the passage layouts need a set-level timer instead.
  • Leaving mid-run. Assumed a student can leave and rejoin while the window is open, with locked answers preserved. Batch 2b's leave dialog depends on this.
  • Bonus visibility during the run. Rendered as showing the live bonus ("bonus +0.3"). If that leaks too much scoring information mid-run, it can be hidden until the finish card.
