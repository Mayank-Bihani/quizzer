Open questions

  • Rejoining a live quiz. The A-variant leave dialog assumes a student can rejoin until the window closes. If leaving is final, that dialog gets much sterner.
  • Notification settings. The account menu lists one; nothing in the brief says notifications exist. Flagged as speculative — remove if there are none.
  • Admin on mobile. Assumed the console is desktop-only and no mobile admin shell is needed; the data-table mobile fallback is provided anyway. Confirm.
  • Board history depth. Pagination assumes leaderboards are per-week and load 20 at a time. If all-time boards exist, numbered pages may be needed there too.
  • Offline answer queueing. The offline strip promises answers submit when connection returns. If the server rejects late submissions, that copy is a lie and must change.
