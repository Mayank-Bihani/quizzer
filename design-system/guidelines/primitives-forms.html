button button · icon-button

One component, five intents, three sizes. Height is the contract: --tap-min 44px standard, 36px only for dense admin toolbars where a pointer is guaranteed, --tap-comfortable 52px for the live-run primary. Loading keeps the button's width so the row never reflows; the label stays and the spinner replaces the icon slot.

Pick sheet — Batch 2a

ComponentABCRecommended

Open questions

  • TITA tolerance visibility. Assumed the tolerance (±0.01) is shown to the student in helper text. If it should be hidden, variant C's format hint has to go too.
  • Negative TITA answers. Assumed answers can be negative and decimal, so the keypad carries "−" and ".". Confirm.
  • CSV image pairing. Assumed images are matched by filename from an image column, and a ZIP entry with no matching row is a warning, not a hard error.
  • Role names. Assumed three roles exactly: student / admin / superadmin, with only superadmin able to promote.
  • Used-count semantics. Assumed "Used ×3" counts quizzes a question has appeared in, and a locked quiz permanently retires its questions (so "Retired" may need to be a fourth badge — flagged for Batch 5).
